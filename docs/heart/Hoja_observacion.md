# Hoja de observación

**Simulador de Boxeo RV**. Pruebas de usabilidad HEART, entregable 5 (semana 14). Una hoja por participante; la rellena la persona que anota (ver `docs/Protocolo_HEART.md`). No se escribe el nombre del participante en ningún sitio.

Al terminar el día, cada hoja se pasa a una fila de `docs/heart/observacion_plantilla.csv` (el nombre de la columna va entre paréntesis). Para "sí / parcial / no", escribir `si`, `parcial`, `no` o dejar vacío si no aplica.

## 2. Adopción sin instrucciones (RNF-03)

Poner el cronómetro en marcha **al oír la primera campana** del nivel 1 (se oye en el visor y en la transmisión). Pararlo en los dos momentos y anotar los segundos. Si el juego se pausa, pausar también el cronómetro.

| Momento | Segundos desde la campana | Notas |
|---|---|---|
| Sube **las dos manos delante de la cara** y las mantiene (`cronoGuardiaS`) | | |
| Primer golpe que **toca al rival** y lo hace reaccionar (`cronoGolpeS`) | | |
| ¿Pidió ayuda o instrucciones? ¿Qué preguntó? (`pidioAyuda`) | sí / no | |

Si a los 2 minutos de juego no ha hecho alguna de las dos cosas, anotarlo y **seguir sin explicarle nada** hasta los 3 minutos; después se le puede orientar con una frase y se anota aquí.
